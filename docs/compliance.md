# 규정 준수 및 서비스 약관

> 이 문서는 메인테이너가 선의로 이해한 내용이며, **법률 자문이 아닙니다.** Anthropic의 약관을 해석하고 변경하는 것은 Anthropic의 몫입니다. 최신 [Claude Code 법적 약관](https://code.claude.com/docs/en/legal-and-compliance)을 읽고 직접 판단하세요.

AIPool은 **직접 호스팅하는 로컬 프록시**입니다. 사용자가 자신의 컴퓨터에서 실행하고, *사용자 본인의* 자격 증명을 보관하며, *사용자 본인의* Claude Code CLI가 보내는 요청을 Anthropic으로 전달합니다. AIPool은 호스팅 서비스가 **아니며**, 누구에게도 "Claude.ai 로그인"을 제공하지 않고, 제3자를 대신해 요청을 라우팅하는 일도 결코 없습니다. 사용자가 직접 관리하는 계정을 통해 사용자 본인의 트래픽만 전달할 뿐입니다.

AIPool을 어떻게 사용하는지는 사용자의 책임입니다. 특히 다음 사항에 유의하세요:

- **정식 Claude Code CLI를 사용하세요.** 서드파티 프런트엔드(opencode 등)에 Pro/Max OAuth 자격 증명을 연결해 쓰는 것은 Anthropic이 명시적으로 제한하는 방식입니다.
- **사람이 개입하는 상태를 유지하세요.** 약관은 완전히 무인으로 돌아가는 자동화가 아니라, 사람이 자리에 있는 대화형 사용을 상정합니다. 스스로 백그라운드 호출을 하는 두 기능인 [keep-warm](quota.md#keep-warm)과 [쿼터 프로브](quota.md#쿼터-프로브)는 **기본적으로 꺼져 있습니다**.
- **정당하게 구매한 구독만 사용하세요.**

가장 많이 받는 질문인 **여러 구독 간 로테이션**에 대해서는, Claude Code 자체의 `/extra-usage` 흐름이 이미 한도에 도달했을 때 *다른* 계정으로 로그인하는 선택지를 제공한다는 점에 주목하세요. "더 사용하려면 본인이 소유한 다른 계정으로 전환하라"는 것은 공식 클라이언트 스스로가 제시하는 방법이며, AIPool은 바로 그 전환을 자동화합니다. Anthropic이 *자동화된* 풀링을 명시적으로 승인한 것은 아니므로 현행 약관에 비추어 따져 보세요. 다만 본인의 구독을 둘 이상 사용하는 것 자체가 본질적으로 금지되어 있다는 생각은, 퍼스트파티 클라이언트가 같은 일을 수동으로 하도록 제안한다는 사실과 양립하기 어렵습니다.

메인테이너가 아는 한, AIPool을 의도한 대로 사용하는 것, 즉 실제 Claude Code CLI와 본인의 구독을 사용하고 사람이 자리에 있는 상태로 사용하는 것은 Claude Code 약관에 부합합니다.
